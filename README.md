Java Project – Bank Account System

About

This project is a console-based Java application that demonstrates basic bank account operations using Java programming concepts.

Features

- Create and manage bank account details
- Perform basic banking operations
- Practice object-oriented programming concepts

Technologies Used

- Java
- Object-Oriented Programming (OOP)

How to Run

1. Install the Java Development Kit (JDK).

2. Download or clone this repository.

3. Open a terminal in the project folder.

4. Compile the program:
   
   "javac BankAccountSystem.java"

5. Run the program:
   
   "java BankAccountSystem"
